More run metrics · timing, gradients, cache and logging
Memory on Apple silicon (unified memory). MLX active = bytes in live MLX arrays (weights, activations, gradients, optimizer state). MLX cache = freed MLX buffers kept for reuse (capped by cache_limit_gb); resident but unused. MLX peak = high-water mark of active since training started. Process footprint = what macOS charges to the training process (Activity Monitor “Memory”). It already includes the MLX/Metal buffers, because GPU and CPU share the same memory — so never add MLX numbers to it. Swap used is system-wide (all processes); growth during the run means the machine is over-committed. Pressure: 1 normal, 2 warning, 4 critical. Any value that could not be read is shown as unavailable.
